# 哲唯科技~GEO交付平台

> 面向 GEO（生成式引擎优化）增长的 SaaS 工作台。设计母题：“暗房显影”——把品牌在 AI 回答里的存在感“显影”出来。
> 当前版本：**前端工作台 + 真实数据后端**（真实爬虫 / GEO 体检 / AI 原创内容生成 / 10 平台绑定与发布 / 分发端口绑定）。

## 一、已实现的模块

| 模块 | 路由 | 说明 |
| --- | --- | --- |
| 工作台看板 | `/` | 曝光/互动/关注 KPI、趋势图、渠道构成、GEO 可见度评分 |
| GEO 体检 | `/audit` | 真实联网分析：生态布局 / 行业横评 / 长尾词 / 官网抓取 / 可选大模型实测，生成 8 章节报告 |
| 报告中心 | `/reports` | 历史报告归档、检索、分级 |
| 报告详情 | `/reports/:id` | 编辑部门风格报告 + 合规免责声明 + 导出 PDF |
| 内容中台 | `/compose` | 手动创作 + **AI 一键生成**原创内容（公司事实驱动、平台合规、GEO 结构化） |
| 发布队列 | `/queue` | 分发状态追踪、失败重试、待发布即时发布（后端在线走真实发布/沙箱发布） |
| 渠道管理 | `/channels` | 10 个平台绑定（OAuth / API Key / Cookie）、健康度、端口状态 |
| 客户管理 | `/clients` | 品牌档案 CRUD、关联账号与数据 |

> 名片页（AI 名片）已按需求移除。

## 二、运行方式

需要 Node.js ≥ 18（检查：`node -v`）。

### 一键启动（推荐）

解压后在项目目录**双击 `start-all.cmd`**，脚本会自动安装依赖、启动后端、启动前端并打开浏览器。

### 手动启动

```bash
cd C:\Users\DELL\Desktop\xianying-geo

# 1) 安装前端依赖
npm install

# 2) 启动后端（真实爬虫 / GEO 分析 / AI 生成 / 平台连接发布 / 端口绑定）
npm run dev:server
#    API: http://localhost:8787   分发平台端口: 9091-9100（已绑定）

# 3) 启动前端（另开一个终端）
npm run dev
#    浏览器打开 http://localhost:5187（/api 自动代理到后端）
```

生产构建：`npm run build`（产物在 `dist/`，静态托管 + 反向代理 `/api` → 后端 8787）。

## 三、后端配置（server/.env）

复制 `server/.env.example` 为 `server/.env` 后按需修改：

- `LLM_API_KEY` / `LLM_BASE_URL` / `LLM_MODEL`：配置大模型后，AI 内容生成与 GEO“AI 回答”实测生效；未配置时自动用启发式生成器（功能仍可用）。
- `SANDBOX_MODE`：`true`（默认）发布为模拟成功；`false` 且填入平台开发者凭证后，发布调用平台真实 API（当前已实现微信公众号草稿示例）。
- `WECHAT_APP_ID` 等：10 个平台的开发者凭证，用于真实 OAuth 绑定与发布。
- `BIND_PORTS`：分发平台服务端口（默认 9091-9100，启动即绑定）。

## 四、真实数据能力（本次已落地）

1. **真实爬取**：后端用 Bing 实时检索品牌生态布局 / 行业横评 / 长尾词，并直接抓取企业官网标题、描述、关键词、栏目（带超时与降级）。
2. **GEO 体检**：`POST /api/geo/audit` 基于真实检索 + 官网抓取 + 可选大模型实测生成完整报告；报告数据来源标注「实测」。
3. **AI 原创内容**：`POST /api/ai/generate` 基于“客户档案 + 官网实抓事实”生成原创、符合各平台字数/格式规则、契合 GEO 结构（疑问句标题、3+ Q&A、小标题分段）的文章或口播脚本。
4. **平台绑定与发布**：`/api/channels/*` 提供 10 平台绑定（OAuth 跳转 / API Key / Cookie）；`/api/publish` 多平台发布；沙箱模式可完整联调，配置凭证后切换真实 API。
5. **端口绑定**：主 API 8787 + 10 个分发服务端口（9091-9100）启动即监听，`/api/ports` 可查。

## 五、合规红线

报告详情页底部已固定声明：本报告基于公开可验证数据的确定性虚拟推理，**不构成对搜索排名、流量、客流或任何收益结果的承诺与保证**。

## 六、技术栈

- 前端：Vite + React 18 + TypeScript；纯手写 CSS 设计系统；SVG 图表；主题深色/浅色/跟随系统。
- 后端：零依赖 Node.js（原生 http + fetch）；真实爬虫（Bing）+ 企业官网抓取 + OpenAI 兼容大模型 + 平台连接/发布适配器。
